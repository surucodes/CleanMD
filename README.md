# CleanMD — LLM Markdown Copy

Chrome/Edge (Manifest V3) extension that copies ChatGPT, Claude and Microsoft 365 Copilot responses as clean Markdown, tuned for **Obsidian** or **Azure DevOps Wiki**. Spec: [Prompts/FRD — LLM Markdown Copy Extension.md](Prompts/FRD%20—%20LLM%20Markdown%20Copy%20Extension.md).

## Load it

1. `npm install`. This also copies Turndown into `lib/`, and `lib/` is what ships.
2. Open `chrome://extensions` (or `edge://extensions`) and turn on **Developer mode**.
3. Click **Load unpacked** and select this folder.
4. After editing any file, click the reload icon on the extension card, then refresh the chat tab.

## Three ways to copy

| Path | What happens |
| --- | --- |
| **Copy as MD** button under each response | Converts that response and puts it on the clipboard |
| Select text in a response, then Ctrl/⌘+C | The selection is converted to Markdown. Partial table selections keep their header row. Selections inside a code block use the normal copy |
| The site's own Copy button | The site copies as usual, then CleanMD replaces the clipboard with its conversion and shows a toast. Code-block copy buttons are left alone |

The last two can each be switched off in the toolbar popup, next to the destination format (Obsidian / Azure DevOps Wiki / plain GFM).

## Layout

```
manifest.json
lib/                 vendored Turndown + turndown-plugin-gfm (generated by npm install)
src/platforms.js     PLATFORM_CONFIG: every host-page selector lives here
src/converter.js     DOM -> Markdown rules + per-format postProcess (also runs in Node)
src/content.js       button injection, MutationObserver, copy interception
src/settings.js      formats + defaults shared with the popup
popup/               format + behaviour toggles (chrome.storage.sync)
test/                node:test + jsdom, covers FRD TC-1..TC-5 and more
```

## When buttons stop appearing

A site redesign has most likely renamed a selector. Open DevTools on an assistant reply, find the element that wraps the rendered markdown, and update `contentSelector` (plus `nativeCopySelector` for the site's Copy button) in [src/platforms.js](src/platforms.js). The Microsoft 365 Copilot selectors are unverified guesses and need checking on first use.
